# Day 2 – Assignment Documentation

## Objective
Implement and analyze Trees, Hashing, Graphs, Two-Pointer techniques and Sliding Window patterns through practical Python applications.

## Set 1 – E-Commerce Catalogue and Traffic Analysis
Implemented BST operations, custom hash table with chaining, Python dictionary lookup, graph traversal, topological deployment ordering, cycle detection, sliding-window traffic analysis and two-pointer pair searching.

## Set 2 – Insurance Claims Processing
Implemented BST operations for claim IDs, normalized hash-based duplicate detection, BFS shortest-path search, DFS cycle detection, consecutive-day claim analysis and two-pointer merging of sorted regional lists.

## Set 3 – Logistics Network and Delivery Windows
Implemented BST operations for hub codes, duplicate parcel scan detection using a hash set, BFS route finding, DFS reachability, four-hour sliding-window analysis and two-pointer palindrome validation.

## Algorithm Analysis
Each set includes a separate complexity and data structure rationale document describing the algorithms, time complexities and reasons for choosing each technique.

## Conclusion
The three sets demonstrate practical applications of fundamental data structures and algorithmic problem-solving techniques using Python.
