# Day 1 – Problem Solving Techniques and Data Structures – I

## 1. Introduction

Day 1 focuses on algorithm basics, data structures, searching techniques, sorting techniques and hands-on problem-solving exercises.

Three practical problem sets were implemented using Python.

## 2. Set 1 – Retail Order Desk

**Problem focus:** Retail order searching, sorting and duplicate detection.

Tasks implemented:
1. Linear Search and Binary Search on 50,000 orders.
2. Selection Sort, Merge Sort and built-in sorting benchmark.
3. Hash-based duplicate order detection.
4. Custom and built-in Stack and Queue.
5. Greedy and Dynamic Programming refund calculation.

**Key result:** Binary Search required 16 comparisons for the tested target, compared with 50,000 for Linear Search.

## 3. Set 2 – Retail Banking Transaction Review

**Problem focus:** Banking transaction searching, statement sorting and duplicate posting detection.

Tasks implemented:
1. Binary Search on 100,000 transaction IDs.
2. Insertion Sort and Merge Sort by posting date.
3. Hash-based duplicate posting detection.
4. Custom Queue and Stack implementations.
5. Divide-and-conquer minimum and maximum transaction calculation.

**Key result:** The implementation compares searching efficiency, sorting stability and transaction analysis approaches.

## 4. Set 3 – Hospital Appointment Desk

**Problem focus:** Patient searching, appointment sorting and scheduling.

Tasks implemented:
1. Linear Search and Binary Search on 20,000 patient records.
2. Selection Sort and Quick Sort by urgency and arrival time.
3. Hash-based double-booking detection.
4. Custom Stack and Queue.
5. Dynamic Programming for appointment scheduling with greedy comparison.

**Key result:** The implementation demonstrates how algorithms and data structures can support hospital appointment management.
