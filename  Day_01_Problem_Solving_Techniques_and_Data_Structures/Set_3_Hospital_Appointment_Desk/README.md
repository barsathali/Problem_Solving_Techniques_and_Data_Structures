# Set 3 – Hospital Appointment Desk

## Project Overview
This project implements searching, sorting, double-booking detection, Stack and Queue operations, and Dynamic Programming for hospital appointment scheduling.

## Tasks Implemented

### Task 1: Searching
- Linear Search and Binary Search.
- 20,000 patient records.
- 1,000 patient lookups.
- Compared execution time.

### Task 2: Sorting
Implemented:
- Selection Sort – O(n²)
- Quick Sort – O(n log n) average case.

Appointments are sorted by urgency level and arrival time. Swap counts and execution times are compared.

### Task 3: Double-Booking Detection
Used a hash-based set to identify repeated patient appointments with the same start and end time.

### Task 4: Stack and Queue
- Custom Queue for walk-in patient tokens (FIFO).
- Custom Stack for recently viewed patients (LIFO).

### Task 5: Dynamic Programming
Implemented Dynamic Programming to calculate the maximum number of non-overlapping appointments a doctor can attend.

Compared the result with a greedy approach.

## Conclusion
All five tasks demonstrate the practical application of searching, sorting, data structures and scheduling algorithms in a hospital appointment system.
